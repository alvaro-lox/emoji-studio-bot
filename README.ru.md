# Emoji Studio: Telegram-бот для эмодзи, стикеров и подарков

[English](README.md)

## Что умеет
Меню разбито на три раздела: **🧩 Эмодзи и стикеры**, **🎁 NFT-подарки** и **🖼 Фото**.

**Режимы** (раздел «Эмодзи и стикеры»), решают, что делать с присланными стикерами и эмодзи:
- **ID эмодзи**: ID премиум-эмодзи, кнопки «Скопировать», «Код» (python-telegram-bot / aiogram / Telethon / Pyrogram).
- **Скачать**: всё, что прислано подряд, приходит одним zip (`.tgs` / `.webm` / `.webp`).
- **Перекрасить**: 10 цветов, 6 градиентов или свой HEX (один цвет или два — для градиента). Тени и блики
  сохраняются; в градиенте тени берут первый цвет, светлые места — второй. Из перекрашенного пака можно
  одной кнопкой создать новый набор в Telegram.

**В любом режиме:**
- **Ссылка на пак** (`t.me/addemoji/…`, `t.me/addstickers/…`) даёт превью всего пака одной картинкой
  и кнопки «Скачать zip», «Перекрасить», «Открыть пак».
- **GIF или видео** превращаются в анимированный премиум-эмодзи 100×100 (WEBM ≤ 3 с). «Добавить в мой пак»
  складывает эмодзи в личный пак пользователя. Эмодзи в подписи к картинке становится значком.
- **Ссылка на подарок** (`t.me/nft/…`) даёт анимацию 60 fps как в Telegram. Под ней кнопки:
  «Без фона», **«Оформление»** (3:2, 1:1 аватар, 9:16 сторис, своя картинка вместо фона, своя подпись или без неё),
  «GIF-файл» (50 fps), «Модель .tgs», **«Скачать подарок»** (zip: MP4, .tgs, кадр PNG, модель без фона, символ и данные),
  **«Следить за владельцем»** (бот напишет, когда сменится владелец; список в `/watches`).
- **Несколько ссылок на подарки** одним сообщением (2–12) — **коллаж** в одной анимации 60 fps: карточки, рамки
  (с отступами или вплотную), круги или пазл с замками; фон подарков вкл/выкл; градиент, живой градиент, тёмный фон
  или своё фото; подписи, заголовок, формат 1:1 / 9:16 / 16:9. Превью обновляется на каждое нажатие.

**🖼 Фото** — пришли фото (лучше файлом, без сжатия) и выбери:
- **Убрать фон** — нейросеть (rembg, ISNet) вырезает объект в полном разрешении, PNG с прозрачностью;
- **Улучшить** — нейросети: увеличение ×4 (Real-ESRGAN general x4v3) убирает шум и артефакты JPEG, лица
  восстанавливает GFPGAN v1.4 (их находит YuNet). Работает на CPU через onnxruntime, 3–12 с на фото;
- **Сделать эмодзи** — премиум-эмодзи 100×100.

**Админ-панель** (`/admin`, `/stats`) для ID из `ADMIN_IDS`: статистика (пользователи, активность, языки,
подарки, коллажи, загрузки, перекраски, эмодзи, фото, превью, слежки), рассылка любого сообщения ровно в том виде,
в каком его прислали (форматирование, премиум-эмодзи, фото, GIF, видео, альбомы) с подтверждением и прогрессом, бан и разбан по ID или пересланному сообщению, список забаненных.

**Защита от перегрузки:** не больше `HEAVY_LIMIT` тяжёлых действий (рендер, перекраска, эмодзи, превью, zip пака)
за `HEAVY_WINDOW` секунд на пользователя, плюс антифлуд (25 апдейтов за 10 секунд). На админов лимиты не действуют.

> Премиум-иконки и цветные кнопки с иконками Telegram показывает, только если у **владельца бота есть Telegram Premium**.
> Без него бот сам переключится на обычные эмодзи (или поставь `CUSTOM_EMOJI=0`).

## Первый запуск
1. Скопируй `.env.example` в `.env`, впиши `BOT_TOKEN`.
2. Запусти бота, напиши ему `/myid` и впиши полученный ID в `ADMIN_IDS`. Перезапусти бота.

С одним токеном может работать **только одна копия** бота. Перед запуском новой версии или на сервере останови старую.

## Сервер (Docker)
```bash
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```
База, кэш и слежки лежат в томе `bot-data`. Обновление: `docker compose up -d --build`.

## Без Docker (Linux)
```bash
sudo apt install python3-venv ffmpeg fonts-inter
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m app
```

## Локально (Windows)
```bash
py -m pip install -r requirements.txt
py bot.py
```

## Настройки (.env)
| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `ADMIN_IDS` | — | ID админов через запятую |
| `ICON_PACK` | `tgiosicons` | пак премиум-эмодзи для иконок |
| `CUSTOM_EMOJI` | `1` | `0`: обычные эмодзи вместо премиум-иконок |
| `BATCH_DELAY` | `2.5` | сколько секунд ждать следующих сообщений перед сборкой zip |
| `HEAVY_LIMIT` / `HEAVY_WINDOW` | `6` / `60` | лимит тяжёлых действий на пользователя |
| `WATCH_INTERVAL` | `900` | как часто проверять владельцев подарков, секунд |
| `MAX_WATCHES` | `20` | сколько подарков может отслеживать один пользователь |
| `RENDER_WORKERS` | `2` | сколько рендеров идёт одновременно |
| `GIFT_SCALE` | `3` | размер анимации (3: 1260×840, 1080×1080, 1080×1920) |
| `FONT_PATH` | — | свой шрифт для подписей |
| `DATA_DIR` | `data` | база SQLite и кэш |

## Структура
Код разбит по разделам бота — так же, как меню.
```
app/
├── main.py            запуск, порядок роутеров
├── config.py          настройки из .env
├── menu.py            главное меню и разделы, язык, помощь
├── nft/               🎁 NFT-подарки
│   ├── parser.py      разбор t.me/nft/<slug>, запасной источник Fragment
│   ├── render.py      анимация 60 fps (rlottie + numpy + ffmpeg), GIF, кадры PNG
│   ├── collage.py     коллаж: карточки, рамки, круги, пазл, живой фон
│   ├── service.py     кэш данных и готовых рендеров, архив подарка
│   ├── watcher.py     фоновая слежка за владельцами
│   ├── handlers.py    карточка подарка, оформление, скачивание, слежка
│   └── collage_handlers.py  настройки коллажа с живым превью
├── stickers/          🧩 эмодзи и стикеры
│   ├── core.py        разбор ссылок и сущностей, код для библиотек, zip
│   ├── downloader.py  сборка присланного в zip
│   ├── recolor.py     перекраска Lottie и WEBP цветом или градиентом, с тенями
│   ├── emoji_maker.py эмодзи 100×100 из картинок и видео
│   ├── packs.py       превью-сетка пака, создание наборов
│   └── handlers/      content (ID, скачивание, превью), recolor, maker
├── photo/             🖼 удаление фона (rembg) и улучшение фото
├── admin/             статистика, рассылка, баны, админы
└── common/            хранилище SQLite, лимиты, тексты RU/EN, иконки, кнопки
```
